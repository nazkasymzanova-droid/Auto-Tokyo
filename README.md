# Автозапчасти — учёт склада

Одностраничный сайт для магазина автозапчастей: остатки, закупки, продажи, контроль дефицита, анализ прибыльности, заказы поставщикам, импорт и экспорт Excel.

## Запуск
- Откройте `index.html` в браузере, либо
- включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Excel
Колонки для загрузки: Артикул, Название, Бренд, Категория, Закупка, Продажа, Остаток, Мин. остаток, Поставщик.

## Данные
Хранятся в localStorage браузера (на устройстве пользователя).
